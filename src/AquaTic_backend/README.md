# AquaTic Backend

This directory contains the backend code for the AquaTic project. The backend is written in [Motoko](https://internetcomputer.org/docs/current/motoko/main/motoko), a programming language designed specifically for the Internet Computer.

## Structure

* `main.mo`: The entry point for the Motoko canister.
* `Types.mo`: Contains type definitions used across the backend.

## Deployment

The backend is deployed as a canister on the Internet Computer. You can deploy it locally using the dfx command-line tool. See the main project README for instructions on how to start the local replica and deploy the canisters.
